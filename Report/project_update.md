# Customer Retention and Revenue Forecasting Analysis
9.06.2026
## Progress Report – Day 1 (Half-Day Work)

### Project Title

Customer Retention Analysis and Revenue Forecasting using E-Commerce Transaction Data

### Objective

The objective of this project is to analyze customer purchasing behavior, measure customer retention through cohort analysis, and forecast future revenue trends to support business decision-making.



## 1. Data Understanding

The dataset contains customer transaction information including:

* Customer ID
* Order ID
* Purchase Timestamp
* Product Information
* Revenue Information

The dataset was reviewed to understand the structure, data types, and business relevance of each field.


## 2. Data Cleaning and Preparation

The following preprocessing activities were completed:

### Duplicate Handling

* Checked for duplicate records.
* Verified transaction uniqueness using order identifiers.

### Missing Value Analysis

* Examined missing values across all columns.
* Removed records with missing customer identifiers where customer tracking was not possible.
* Verified that the remaining data was suitable for customer-level analysis.

### Data Type Validation

* Converted purchase timestamp into DateTime format.
* Verified numerical fields used for revenue calculations.

### Feature Engineering

Created additional analytical fields:

* Order Month
* Cohort Month
* Cohort Index

These fields are required for customer retention analysis.


## 3. Cohort Analysis

### Purpose

Cohort analysis was performed to evaluate customer retention over time.

### Methodology

#### Step 1: Cohort Identification

Customers were grouped according to their first purchase month.

#### Step 2: Order Month Extraction

Purchase dates were converted into monthly periods.

#### Step 3: Cohort Index Creation

A cohort index was calculated to determine the number of months elapsed since the customer's first purchase.

Example:

| Cohort Month | Order Month | Cohort Index |
| ------------ | ----------- | ------------ |
| Jan-2018     | Jan-2018    | 1            |
| Jan-2018     | Feb-2018    | 2            |
| Jan-2018     | Mar-2018    | 3            |

#### Step 4: Retention Matrix Construction

A retention matrix was generated by calculating the percentage of customers returning in subsequent months.

Example:

| Month | Retention |
| ----- | --------- |
| 1     | 100%      |
| 2     | 40%       |
| 3     | 25%       |
| 4     | 15%       |

#### Step 5: Cohort Heatmap

A heatmap was created to visualize customer retention patterns across cohorts.

---

## Preliminary Findings

* Customer retention decreases over time.
* Most customer attrition occurs within the first few months after acquisition.
* Certain cohorts demonstrate stronger retention compared to others, indicating possible differences in customer engagement or acquisition quality.
