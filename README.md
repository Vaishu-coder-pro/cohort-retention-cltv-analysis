# Second Half Update (09.06.2026)

During the second half of the day, I completed the Cohort Retention Analysis section of the project. I created the Purchase Month, Cohort Month and Cohort Index features and used them to generate the retention matrix and retention rate table for analysing customer retention behaviour over time.

I also completed the Business Insights Analysis using the cleaned dataset. This included calculating overall business metrics such as total revenue, total customers, total orders and average delivery days. In addition, I analysed revenue by product category, state-wise revenue distribution, payment methods and delivery performance.

The required datasets generated from the analysis were exported and organised for future dashboard development. I updated the project notebooks with outputs and explanations, organised the project folder structure, added screenshots of important results, and updated the README and progress documentation files in the GitHub repository.

All completed work was pushed to GitHub through separate commits for proper project tracking and version control.
