# Customer Analytics and Churn Prediction Platform

## Project Overview

This project is an end-to-end customer analytics platform developed using the Olist E-commerce dataset. The objective is to analyse customer behaviour, identify high-value customers, predict customer churn, and generate business insights to support data-driven business decisions.

## Project Objectives

* Perform customer segmentation using RFM Analysis.
* Calculate Customer Lifetime Value (CLTV).
* Analyse customer retention using Cohort Analysis.
* Generate business and product performance insights.
* Segment customers using Machine Learning clustering techniques.
* Identify and predict customer churn.
* Create dashboard-ready datasets for business intelligence applications.
